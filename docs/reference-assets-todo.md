# Reference and base assets still to record

These templates are `motion_transfer` or `face_swap` and ship with `referenceVideo` / `baseVideo` set to null.
Do not download a competitor's sample video and drop it in here. Record the motion yourself, or use a clip you have a license for, then save it at the path below.
Until that file exists, job creation keeps the template's type on record and renders it as image-to-video, with a warning in the server log.

Accepted files: `.mp4`, `.mov`, or `.webm`. Large media in these folders is gitignored.
